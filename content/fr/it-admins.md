# Hack Club pour les administrateurs informatiques
Si vous lisez ceci, vous êtes probablement administrateur informatique au sein de votre organisation. **Voici un aperçu rapide de ce dont nous avons besoin de votre part.**

Veuillez mettre en liste blanche ou débloquer les domaines suivants :

- `*.hackclub.com` - domaine principal de Hack Club, héberge les ateliers, les outils et d'autres contenus
- `hack.club`, `hack.af` - raccourcisseur de liens utilisé pour divers liens (maintenu par Hack Club)
- `*.github.com`, `*.github.io` - GitHub, une norme de l'industrie pour l'hébergement de code et la collaboration, détenu par Microsoft.
- `hackclub.slack.com`, `hackclub.enterprise.slack.com` - plateforme de communication principale de Hack Club
N'hésitez pas à poursuivre votre lecture pour plus de détails et d'éventuelles alternatives.

## Hack Club Sites

Si vous ne pouvez pas autoriser tous les sous-domaines, veuillez autoriser les suivants :

- `hackclub.com` - Site web principal.
- `auth.hackclub.com` - Coffre-fort d'identité central.
- `ysws.hackclub.com` - Liste des programmes en cours.
- `workshops.hackclub.com` - Tutoriels de projets pour débutants.
- `jams.hackclub.com` - Guides communautaires avancés.
- `clubs.hackclub.com` - Tableau de bord tout-en-un du club.
- `leaders.hackclub.com` - Portail de gestion des leaders.
- `spaces.hackclub.com` - Environnement de développement basé sur le navigateur.


## GitHub
GitHub est la plateforme de référence du secteur pour héberger du code et y collaborer. Son déblocage permet aux élèves de publier leurs projets et d’acquérir des compétences applicables à leur future carrière ; même un accès supervisé et limité dans le temps est précieux.

## Inspect Element / Developer Tools
Les outils de développement du navigateur (p. ex. Inspect Element) sont recommandés pour les projets de développement web, afin que les sites puissent être débogués et stylisés.

## Qui sommes-nous ?
Vous êtes peut-être ici parce qu’un élève a demandé à lancer un [Hack **Club**](https://hackclub.com/clubs) au sein de votre organisation. Les Clubs sont un excellent moyen de promouvoir le code auprès des adolescents de votre communauté. Vous pouvez en savoir plus sur notre [philosophy](https://hackclub.com/philosophy) et notre [philanthropy](https://hackclub.com/philanthropy). Si vous avez d’autres questions, n’hésitez pas à contacter le Clubs Department à [clubs@hackclub.com](mailto:clubs@hackclub.com).
