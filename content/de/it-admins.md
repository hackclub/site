# Hack Club für IT-Administratoren
Wenn Sie dies lesen, sind Sie wahrscheinlich ein IT-Administrator in Ihrer Organisation. **Hier erhalten Sie einen kurzen Überblick darüber, was wir von Ihnen benötigen.**

Bitte setzen Sie die folgenden Domains auf die Whitelist oder entsperren Sie sie:

- „*.hackclub.com“ – die Hauptdomain von Hack Club, beherbergt Workshops, Tools und andere Inhalte
- „hack.af“ – Link-Shortener für verschiedene Links
- „*.github.com“, „github.dev“ – GitHub, ein Industriestandard für Code-Hosting und Zusammenarbeit, im Besitz von Microsoft.
- „hackclub.slack.com“, „hackclub.enterprise.slack.com“ – die primäre Kommunikationsplattform von Hack Club

Lesen Sie weiter, um weitere Einzelheiten und mögliche Alternativen zu erfahren.

## Hack-Club-Sites

Wenn Sie nicht alle Subdomains auf die Whitelist setzen können, setzen Sie bitte Folgendes auf die Whitelist:

- „hackclub.com“.
- „workshops.hackclub.com“.
- „jams.hackclub.com“.
- `sprig.hackclub.com`

## GitHub

Neben den typischen HTTP(S)-Ports müssen die Ports 22 und 9418 für SSH bzw. Git geöffnet sein.

## Element/Entwicklertools prüfen

Für Webentwicklungsprojekte sind Browser-Entwicklertools (z. B. Inspect Element) erforderlich, damit Websites debuggt und gestaltet werden können.
