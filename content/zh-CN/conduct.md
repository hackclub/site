# 行为准则

## 核心初衷

大多数网络空间的状态介于加油站与核废料垃圾场之间。在最好的情况下，人们来了，拿走所需之物，然后离开。在最坏的情况下，人们互相伤害、彼此投毒，伤害自己，也毒害周围的一切。

但事情本不必如此。网络社区完全可以成为一个受人尊重、彼此关心的港湾。它甚至可以成为你一生中最棒的社区。这正是我们在 Hack Club 所致力的目标。当你加入我们时，你便承诺将与我们共同打造这样的社区。这绝非易事，但意义非凡。你的任务就是恪守以下准则：

1. 善待每一个人，心怀尊重与善意
2. 爱护我们的共享空间，不使其恶化贬损
3. 化解冲突，让沟通富有成效
4. 追求卓越至善，而不止于“不犯规”

这些准则始终是好的，但并非在所有情境下都一目了然，因此请继续阅读下文，了解我们在实践中如何贯彻它们。没有任何一套死板的规则能够完美涵盖每种情况下的正确做法。我们将始终用这些价值观来要求你，也要求我们自己。如果你违背了这些价值观，我们会尽力引导你做出改变。如果你拒绝改变，我们将请你离开 Hack Club。

## 善待每一个人，心怀尊重与善意

1. 友善且热忱待人
2. 切勿发表任何侮辱、贬损、仇恨或威胁性的言论
3. 切勿在言语或行动中歧视他人
4. 切勿骚扰或霸凌他人
   - 如果有人请你不要打扰他们，哪怕你出于善意，也必须立刻停止打扰
5. 切勿发起不受欢迎的恋爱或性暗示举动
   - 如果你不确定对方是否欢迎，就绝不要轻举妄动

## 爱护我们的共享空间，不使其恶化贬损

1. Hack Club 的空间应当是健康纯粹、高质量的。切勿发布：
   - 色情或涉性内容
   - 垃圾信息
   - 几乎任何事情如果做得过度，都会变成垃圾信息
   - 未经总部许可的商业广告
2. 契合情境适度表达。某些言行在特定语境下或许可行，但在另一种语境下便可能违反《行为准则》。例如：
   - 破坏或打断严肃讨论的玩笑或表情包
   - 向不想听或不想透露个人信息的人分享或索取个人信息
   - 在不想谈论敏感/不适话题或年龄尚小无法谈论的人身边讨论此类话题
3. 切勿企图欺诈 Hack Club。我们依靠善款维持运营。欺诈所掠夺的资金并不是来自某家庞大而冷漠的巨头企业，而是从另一名青少年手中夺走的。

## 化解冲突，让沟通富有成效

1. 当他人与你意见不一致时，首先尝试理解他们的想法及其背后的原因
2. 保持克制，切勿激化矛盾，即便受到挑衅也是如此
3. 切勿拉帮结派、煽动针对他人的敌对情绪
4. [假定善意。](https://en.wikipedia.org/wiki/Wikipedia:Assume_good_faith)
5. 保持耐心
6. 换位思考，斟酌自己的言辞会被如何理解。富有成效的沟通需要付出努力
7. 在激烈或节奏极快的对话中，发言前先思考片刻
   有时，最好的选择是保持沉默
8. 如果你需要帮助，请随时联系社区管理团队

## 追求卓越至善，而不止于“不犯规”

参与 Hack Club 的错误方式是去问：“遵守规则的最低底线是什么？”。

参与 Hack Club 的正确方式是去问：“一个善良正直的人在这种情况下会怎么做？”，然后付诸行动——即使你并不想这么做，即使你认为规则并没有硬性要求。

我们每个人有时都会犯错。当你出现疏忽时，切勿向自己或他人找借口说“这并没有违反规则”。

## 《行为准则》的适用范围

- 我们的 Slack
- 俱乐部
- 各类活动（线上或线下）及附属项目
- 我们的 GitHub 组织和代码仓库
- HCB 上的学生自管组织

本行为准则适用于参与这些空间的所有人，包括 Hack Club 成员、志愿者、全职工作人员以及往届校友。

当 Hack Club 成员在非 Hack Club 空间相互交往并违反行为准则时，我们依然可能采取相应措施。

这份《行为准则》绝非刻板生硬的法律套话。这是我们针对“如何将 Hack Club 打造为一个改变人生的非凡社区？”这一问题所给出的郑重回答。我们珍视《行为准则》，因为我们珍视你们每一个人。
