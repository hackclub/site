# Hack Club 活动青少年保护政策

所有 Hack Club 线下活动（包括分站卫星活动和旗舰活动）均必须严格遵守我们的《青少年保护政策》。如有任何疑问，请致信 [safety@hackclub.com](mailto:safety@hackclub.com)。

1. 宗旨与目标

    1.1 概述

    * 本《青少年保护政策》（下称“本政策”）旨在确保 Hack Club 的所有参与者、志愿者、导师和工作人员都能享有安全、受尊重与受支持的环境。它体现了 Hack Club《行为准则》的精神（尊重、善意与包容行为）。

2. 适用范围

    2.1 适用对象

    * 本政策适用于全球参与 Hack Club 活动的所有人员：
        * 参与者（13–18 岁）
        * 参与者的父母/监护人
        * 组织者、活动工作人员与志愿者
        * 导师、特邀演讲嘉宾、外部供应商与场地工作人员
        * 出现在活动现场的任何其他人员

        本政策覆盖所有活动区域（活动场馆、休息/就寝区域（如适用）、公共空间）以及活动相关环节（活动前筹备、24 小时/12 小时活动全程、社交互动时间、活动结束后的收尾工作）。

    2.2 保护原则

    * 无论年龄、背景、身份或个人特征如何，每个人都必须受到尊严、尊重与公平的对待。这包括但不限于个人的性别认同、生理性别、族裔、残疾障碍、种族或语言。

    * 未成年人的安全与福祉必须是首要且最重要的考量因素。

    * 言行举止必须符合 Hack Club《行为准则》：杜绝欺凌、骚扰、歧视或任何不当的人际交往行为。

    * 任何安全隐患或突发事件均须使用我们的事件举报表单（详见第 6.3 节）迅速上报（上报时效依据我们的[分级响应指引图表（Triage Chart）](https://attend.hackclub.com/docs/organizers/reporting-incidents)执行），并在确保报告严格保密的前提下谨慎妥善处置。事件审核人员必须提供始终如一的支持，并针对就报告所采取的处置行动给出确凿充分的理由。

    * 我们秉持“谨慎关照义务（Duty of Care）”思维：主动排查防范风险，而不仅仅是在问题出现后被动响应。所有参与者、志愿者、导师和工作人员如发现任何关切隐患或突发事件，均须向对接联系人/安全保护专员报告。

3. 角色与职责

    3.1 本地活动负责人 / 对接联系人

    * 负责青少年保护措施的落地执行与整体监管。

    * 确保所有工作人员/志愿者接受培训交底，熟知并掌握本政策。

    3.2 安全保护专员

    * 所有经批准举办的 Hack Club 活动均须指定一名或多名接受过安全保护专门培训（例如安全空间、儿童保护）的专职工作人员。
    * 这些专员将通过我们的在线培训模块接受考核培训。

    * 专员资质认证记录可应要求提供查验。

    * 专员的联系方式须清晰传达给所有参与者、志愿者以及父母/监护人。这些联络信息必须以书面形式（例如在活动官方网站上）保持公开可查。

    * 专员负责受理所有关于安全保护关切或事件的报告。

    * 必要时，专员负责与场地安保部门或紧急救援机构进行联络对接。

    3.3 工作人员与志愿者

    * 所有工作人员和志愿者必须严格遵守本政策，具备儿童保护指南的基础认知，并同意遵循 Hack Club《行为准则》。

    * 工作人员和志愿者必须懂得识别潜在的危险信号（欺凌、骚扰、虐待透露、心理危机），并明确知道如何报告所观察到的危险迹象。

    * 工作人员和志愿者必须向所有参与者明确说明本文所述的举报途径。包括为他们提供清晰明了的书面举报指南，并明确告知他们绝不会因提交举报而受到任何不利对待，除非该举报被确凿证实属于恶意捏造。

    * 工作人员和志愿者必须与参与者保持适当的界限（包括肢体接触、线上沟通和言谈交流），且绝不可在没有他人的情况下单独与未成年人同处一室。

    * 工作人员和志愿者不得在其他工作人员视线范围之外的私密空间与未成年人单独互动。

    * 与参与者进行的所有数字化沟通必须通过 SLACK 或 HACK CLUB 官方邮箱进行。仅在 Slack 或 Hack Club 邮箱不可用或功能受限时，方可使用 WhatsApp、Discord 或其他常用通讯工具。我们鼓励组织者尽量在有两名及以上工作人员在场的群聊中进行交流。

    3.4 参与者

    * 所有活动参与者均须遵守 Hack Club [《行为准则》](https://hackclub.com/conduct)及本《青少年保护政策》。做一个善良正直的人。

    * 参与者必须清楚违反行为准则可能招致的后果。

    * 参与者有责任主动学习《行为准则》，并对其个人违规行为承担全部责任。

    * 必须让参与者知晓举报途径，并在目睹或遭遇违规行为时指导他们该向谁反映。

    3.5 父母 / 监护人

    * 父母/监护人必须代表未成年参与者签署并提供活动参与同意书、紧急联系人信息、肖像及媒体使用授权，并披露任何相关的医疗状况或特殊支持需求。（详见第 6.7 节）

    * 父母和监护人必须明确知悉本政策、应急预案以及在活动期间随时联系组织者的方式。组织者须在合理时间内及时解答并处理家长的任何顾虑。

    * 父母和监护人同样必须遵守本政策及《行为准则》，并在与任何工作人员或参与者交往互动时保持相互尊重。

    * 为确保所有参与者的安全与自在，除非活动组织者另有明确许可，否则父母和监护人不得在活动场地区域内逗留。

4. 风险管理与环境

    4.1 场地与监督管理

    * 活动场地必须进行安全评估，并在活动开始前完成全面的风险评估。活动前必须对以下安全考量进行核查并形成书面记录：

    1. 应急疏散通道的位置及畅通状态

    2. 洗手间设施的无障碍通行能力（美国境内的场馆必须符合 ADA《美国残疾人法案》要求）

    3. 安全就寝/休息区域的可用性（若活动涉及过夜休息）

    4. 合格适宜的照明采光（最好可由活动工作人员自行调节控制）

    5. 场馆所有出入口的安全防护（出入口必须安排专人值守或配备门禁加锁，防止未经授权的人员擅自进入）

    * 在活动全程中，必须根据参与者的人数和年龄，配备充足的成年工作人员（达到所在司法管辖区法定成年年龄的工作人员）进行现场监督。我们的建议配比为 1 名工作人员对应 15 名参与者。

    * 严禁参与者在受限或偏僻区域无人看护随意走动。在整个活动期间，除非获得工作人员的明确离场许可，否则参与者必须始终留在活动既定安全范围内。

    * 为满足参与者的多样化需求，在场地空间允许的情况下，每个活动均应设立指定的安静专注工作区和安静休息放松室。

    4.2 签到与离场签退

    * 参与者的到场与离开必须使用官方提供的管理工具（Attend、Cockpit 等）进行严格登记（记录到达时间、姓名、监护人联络方式及已签署的同意书）。

    * 若参与者可能在活动中途离开场地，活动组织者必须提前制定明确的离场方案程序（例如家长/监护人当面签退领回、工作人员陪同护送等）。

    * 未成年参与者中途离场必须获得其父母的书面明确同意。组织者有责任在核准参与者离场前确认并归档该书面许可。

    4.3 导师与参与者的边界界限

    * 导师和工作人员不得向参与者透露个人私人联系方式（个人私人手机号、个人社交媒体账号等）。可应要求提供工作邮箱、Hack Club Slack 用户 ID 以及 Hack Club 配发的电话号码。

    * 允许进行一对一辅导，但必须在视野开阔的公共开放区域进行，且现场至少有另一名志愿者在场。

    * 肢体接触必须得体端庄、由参与者主动发起、符合文化习俗习惯、征得对方同意且降至最低限度。（例如：握手和击掌完全可以，但拥抱通常不合适。）

    4.4 行为规范准则

    * 严禁任何参与者、组织者或工作人员非医嘱使用、销售或交易酒精、烟草、大麻以及任何受管制的麻醉受控药物。

    * 凡被发现在活动期间受酒精或违禁药物影响（处于醉酒或吸毒状态）的人员，将面临极其严肃的处理后果。这是 Hack Club 不可逾越的绝对红线，甚至可能直接移交当地执法机关处理。

    * 严禁在任何参与者的沟通交流、展示汇报中出现不当内容（涉及色情、暴力、歧视等）。何种情况构成不当内容由 Hack Club 工作人员全权裁量。违者将被转交 Hack Club 行为准则处理小组（亦称消防队/Fire Department）。

    * 严禁参与者和组织者利用活动官方沟通渠道散布不良或仇恨言论、兜售推销产品或服务，或骚扰其他参与者与组织者。违者将被转交 Hack Club 行为准则处理小组（亦称消防队/Fire Department）。

    * 参与者、组织者和工作人员均应严格遵守安静作息/熄灯时间、休息间隔、饮水补给以及个人健康身体需求。

5. 医疗与应急处置程序

    5.1 急救措施

    * 每个活动均应根据所在国卫生部门的指导规范配备物资齐全的急救箱。我们强烈建议组织者按每 55 名参与者配备 1 人的比例，熟练掌握急救箱的使用方法。

    * 参与者必须提前向 Hack Club 申报相关医疗/健康状况信息（过敏史、既往病史、正在服用的处方药物等）。

    * 紧急联系人信息及监护人联系方式必须存放于安全且便于活动组织者随时紧急调阅的位置。

    * 必须通过急救事件记录表维护事件台账记录（发生时间、涉及人员、事件描述、采取的救护措施）。

    * 仅当父母/监护人在 Attend 系统中给予了明确书面许可，且严格限于表格中核准的具体药品（包括品牌、品名、剂量和给药时间）时，方可提供非处方药（OTC）。

6. 参与者福祉与安全保障

    6.1 识别安全关切

    * 安全关切迹象包括（但不限于）：
        * 欺凌、骚扰、歧视或强迫威胁。
        * 性骚扰、性虐待、身体侵害或不当亲密行为
        * 参与者主动吐露个人安全关切困境（如自残倾向、家庭虐待等）
        * 工作人员/志愿者逾越身体接触或情感边界
        * 心理健康危机，或参与者出现反常举动对自己或他人构成人身危险。

    6.2 报告机制

    * 必须在线上和现场设置醒目清晰的标识指引，告知参与者/监护人如何联系活动组织者和 Hack Club 官方团队。

    * 工作人员/志愿者发现任何隐患必须立即向首席组织者/主要联系人报告。

    * 发生任何事件均必须通过相关行政管理工具（即 Attend）填写并提交事件报告表。

    * 任何人均可通过 Attend 的事件工具提交报告，访问链接请见 [此处](https://hack.club/incident)，亦可在浏览器中直接输入 hack.club/incident。

    6.3 强制上报规定

    * 强制提交：无论情节轻重，所有涉及青少年保护的事件均必须由活动负责人或安全保护专员在事件发生后 18 小时内，通过 Hack Club 组织者控制面板尽早完成上报。

    * 保密性：通过 Hack Club 工具提交的报告均严格保密，仅限 Hack Club 总部工作人员和指定的专职安全保护人员查阅。

    * 上报时效：遇到危急生命情况，须立即拨打当地急救与报警电话。对于紧急突发事件（存在即刻人身危险、严重伤害或触发法定强制上报义务的情形），在联系属地紧急救援部门后，必须立即通过电话（[+18556254225](tel:18556254225)）或电子邮件（<safety@hackclub.com>）向 Hack Club 总部紧急报告，并完成 [在线表单提交](https://hack.club/incident)。

    * 违规后果：未能按规定履行强制上报责任的组织者，可能会被取消未来主办 Hack Club 活动的资格，并可能直接影响该活动的保险承保效力及 Hack Club 的官方支持。

    * 协助支持：Hack Club 总部将逐一审核所有报告，提供处置步骤指引，并协助组织者妥善应对复杂疑难局面。报告积累的经验将用于持续改进提升所有 Hack Club 活动的安全保护水平。

    6.4 保密原则与支持援助

    * 所有事件报告都将在高度保密下存储与处理。相关信息仅在“确有知情必要”的严格范围内共享。

    * 必须向所有受影响的参与者提供关怀与支持（例如在适当时通知联系家长）。

    * 绝不容忍对报告安全隐患或在活动中遭遇欺凌伤害的人员采取任何形式的报复或歧视。

    6.5 违规纪律处分

    * 一旦 Hack Club 团队成员或活动负责人获悉参与者/工作人员/志愿者存在违规失范行为，对违规者的处分措施可能包括：口头/书面警告、逐出活动现场、遣送回家（须与监护人取得联系对接），以及/或永久禁止参加未来的活动或彻底除名出 Hack Club。

    * 严重违规行为（虐待、暴力、性不端行为）将导致立即驱逐出场并移交执法机关。正如前文所述，未成年人的安全与福祉是我们最核心首要的考量。

    * 所有处置行动均将秉持公平公正与公开透明原则，坚守活动既定的《行为准则》底线。

    6.6 总结复盘与持续改进

    * 活动结束后，组织者将举行青少年安全复盘会议，系统审查记录在册的各类事件、汲取的经验教训以及收集到的各方反馈。
    * 本政策每年进行一次全面修订评估。
    * 所有政策修订更新将清晰通报传达给未来的参与者/工作人员/志愿者。

    6.7 监护人知情同意与参与

    * 未成年人参与活动必须取得其父母/监护人的明确知情同意书。同时必须申报提交以下信息：
    * 参与者详细信息（姓名、年龄、就读学校）
    * 紧急联系人（及电话）
    * 必要的医疗和/或健康信息（过敏原、日常用药、特殊支持需求）
    * 参与者是否有特殊的考勤出席限制（例如需提前离场）
    * 父母/监护人必须提前收到活动日程表、入场/散场离场时间、场馆详细地址，以及安全保护专员与首席组织者的紧急联络电话。
    * 若参与者在活动结束前未经事先批准擅自离开场馆，必须第一时间通知该学员的父母/监护人，并报备安全保护专员。
