# Hack Club IT 管理员指南
如果您正在阅读本文，您很可能是贵机构的 IT 管理员。**以下是我们希望您协助配置的网络权限概览。**

请将以下域名加入白名单或予以放行：

- `*.hackclub.com` - Hack Club 的主要域名，承载工作坊教程、在线工具及其他社区内容
- `hack.club`、`hack.af` - 用于各类链接的短链接服务（由 Hack Club 维护）
- `*.github.com`、`*.github.io` - GitHub，微软旗下的行业标准代码托管与协作平台
- `hackclub.slack.com`、`hackclub.enterprise.slack.com` - Hack Club 的主要沟通交流平台

欢迎继续阅读下文以了解更多技术细节和替代方案。

## Hack Club 站点列表

如果您无法放行所有二级子域名，请至少将以下域名加入白名单：

- `hackclub.com` - 官方门户首页。
- `auth.hackclub.com` - 统一身份认证与账户中心。
- `ysws.hackclub.com` - 正在运行的激励项目列表。
- `workshops.hackclub.com` - 初学者项目动手教程。
- `jams.hackclub.com` - 进阶社区实践指南。
- `clubs.hackclub.com` - 一站式俱乐部管理控制面板。
- `leaders.hackclub.com` - 俱乐部社长管理门户。
- `spaces.hackclub.com` - 基于浏览器的在线开发环境。


## GitHub

GitHub 是业界用于代码托管与团队协作的标杆平台。放行 GitHub 能让学生公开发布他们的编程项目，并掌握对未来职业生涯大有裨益的技能；即便是受监督的、限时的网络访问，对学生而言也极具价值。

## 审查元素 / 开发者工具

对于 Web 开发项目，建议启用浏览器开发者工具（例如“检查元素”/Inspect Element），以便学生调试网站并调整样式。

## 我们是谁？

您看到这篇指南，可能是因为有学生申请在贵机构创办 [Hack **Club**](https://hackclub.com/clubs)。俱乐部是在您所在的社区中向青少年普及编程的绝佳形式。您可以进一步了解我们的[理念](https://hackclub.com/philosophy)与[公益慈善](https://hackclub.com/philanthropy)。如果您有任何其他疑问，欢迎随时发送邮件至俱乐部事务部 [clubs@hackclub.com](mailto:clubs@hackclub.com) 与我们取得联系。
